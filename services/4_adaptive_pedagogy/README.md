# 🎓 Service 4: Adaptive Pedagogy & Assessment Intelligence

مرحباً بك في مجلدك الخاص يا مهندس الذكاء التعليمي (أنت)! 🌟  
هنا يكمن السحر الحقيقي للمشروع؛ تحويل النظام من مجرد محرك بحث لمعلم ذكي يفهم عقلية الطالب!

---

## 🎯 دورك في المشروع باختصار (Mission):
المحاضرات مش مجرد ملخصات؛ الطالب محتاج يقيس فهمه ويتدرب بنظام. دورك:
1. **توليد أسئلة بلوم المعرفية (Bloom-Taxonomy Question Bank)**:
   - أسئلة MCQ موجهة عبر مستويات بلوم (تذكر، فهم، تطبيق، تحليل، تقويم).
   - **Diagnostic Distractor Mapping**: كل خيار خاطئ في السؤال مربوط بفرضية مفهوم خاطئ محدد (`misconception_id`)؛ عشان لما الطالب يغلط نعرف هو فاهم إيه غلط بالظبط مش بس إنه غلط.
   - أسئلة مقالية مع **معايير تصحيح مهيكلة (Structured Rubrics)** ونماذج إجابة كاملة وتصحيح آلي فوري.
2. **تتبع المعرفة البايزي (Bayesian Knowledge Tracing - BKT)**:
   - حساب احتمالية إتقان الطالب لكل مفهوم $P(L)$ مع عزل عامل الحظ (التخمين Guess) والغلطة العفوية (الزلة Slip).
3. **جدولة المراجعة التباعدية (FSRS-4.5 Scheduler)**:
   - حساب استقرار الذاكرة وصعوبة كل مفهوم لكل طالب لتحديد الموعد الأمثل للمراجعة قبل نسيان المعلومة.
4. **التدريس التكيفي وخطط العلاج (Adaptive Remediation)**:
   - لما الطالب يواجه صعوبة في مفهوم معين، المنظومة بترجع تلقائياً لشجرة المعرفة وتشوف المتطلبات السابقة غير المتقنة وتشرحها له الأول (وفق منطقة النمو القريب ZPD).

## 📂 خريطة المجلد ومسؤولية كل ملف:

```
4_adaptive_pedagogy/
├── bloom_engine/
│   ├── mcq_generator.py        # توليد أسئلة MCQ وتوزيع المشتتات التشخيصية (Distractors)
│   └── essay_evaluator.py      # توليد الأسئلة المقالية وتصحيح إجابات الطالب بالـ Rubrics
├── bkt_engine/
│   ├── bkt_updater.py          # معادلات التحديث البايزي للاحتماليات (Mastery Update)
│   └── student_state_store.py  # إدارة وتخزين ملف إتقان الطالب لكل مفهوم
├── fsrs_scheduler/
│   └── memory_optimizer.py     # تطبيق خوارزمية FSRS لجدولة المراجعات القادمة
├── misconception_analyzer/
│   └── error_diagnoser.py      # تحليل أنماط أخطاء الطالب وكشف الفجوات المعرفية التراكمية
└── pedagogy_coordinator.py     # المنسق العام لربط الأسئلة بالتقييم وتحديث مستويات الإتقان
```

## 🔄 ترتيبك في الفريق (مين هيديك ومين هتسلم له):
* **📥 مين بيديك داتا؟**  
  - مهندس الذاكرة (**Service 2**): بيديك شجرة المفاهيم (PKG Concepts) عشان تبني عليها الأسئلة.
  - مهندس الـ RAG (**Service 3**): بيديك مقاطع الأدلة والشروحات الموثقة.
* **📤 مين هتسلمه داتا؟**  
  - واجهة المستخدم (**Service 5**): بتسلمها بنك الأسئلة بالكامل، وخطط المراجعة، وتقارير التشخيص.
  - مهندس الـ RAG (**Service 3**): بتديه حالة إتقان الطالب (`bkt_p_mastery`) عشان يكيّف مستوى صعوبة الشرح التفاعلي.
