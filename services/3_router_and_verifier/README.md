## 🎯 دورك في المشروع باختصار (Mission):
الموديل التوليدي لوحده بيهلوس ومينفعش نثق فيه في امتحانات ومحاضرات جامعية. دورك:
1. **توجيه الاستعلامات التكيفي (6-Route Adaptive Query Planner)**:
   - سؤال مباشر عن دقيقة في فيديو؟ $\rightarrow$ روح للوقت فوراً وتخطى البحث المتجهي.
   - سؤال رياضي أو مفاهيمي؟ $\rightarrow$ بحث هجين (Dense + BM25) وإعادة ترتيب (Cross-Encoder).
   - سؤال مقارنة بين موضوعين؟ $\rightarrow$ فكك السؤال لسؤالين واسترجع أدلة متوازنة للاثنين.
   - سؤال عابر لعدة محاضرات؟ $\rightarrow$ اجتز شجرة المعرفة (PKG Subgraph Traversal).
   - ملخص شامل؟ $\rightarrow$ استخدم ملخصات RAPTOR في نافذة السياق.
   - معلومة مش موجودة في المنهج؟ $\rightarrow$ امتناع معاير (Calibrated Abstention) وقول بوضوح: "المعلومة دي مش في المحاضرة".
2. **بوابة التحقق الصارمة (Claim-Level Verification Gate)**:
   - تفكيك إجابة الموديل لادعاءات ذرية (Atomic Claims).
   - فحص كل ادعاء بنموذج الاستلزام المنطقي `mDeBERTa-v3-base-xnli` للتأكد إنه مشتق من نص المحاضرة.
   - فحص المعادلات بخوارزمية `SymPy` للتأكد من التكافؤ الجبري للرموز الرياضية.

## 📂 خريطة المجلد ومسؤولية كل ملف:

```
3_router_and_verifier/
├── routers/
│   ├── adaptive_router.py      # تصنيف السؤال واختيار أفضل مسار استرجاعي
│   └── query_decomposer.py     # تفكيك أسئلة المقارنات إلى استعلامات فرعية مستقلة
├── verifiers/
│   ├── nli_verifier.py         # نموذج mDeBERTa لفحص الاستلزام المنطقي (Entailment)
│   ├── sympy_verifier.py       # محرك SymPy للتحقق الرمزي من صحة المعادلات الرياضية
│   └── contradiction_gate.py   # كشف التعارضات بين المحاضرات المتقدمة والتمهيدية
├── llm_adapters/
│   └── gemini_orchestrator.py  # استدعاء نماذج Gemini 2.5 Flash / Pro بأوامر مهيكلة
└── rag_engine.py               # الملف الرئيسي لتنسيق دورة الاسترجاع والتحقق كاملة
```
