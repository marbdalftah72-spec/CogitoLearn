# 🖥️ Service 5: Interactive Learning Workspace & Evaluation Harness

مرحباً بك يا مهندس النظام والواجهة! 👋  
أنت واجهة المشروع أمام العالم ولجنة المناقشة؛ كل تعب الفريق بيظهر من خلال شغلك!

---

## 🎯 دورك في المشروع باختصار (Mission):
المستخدم والدكتور مش هيشوفوا الكود من ورا، هيشوفوا السيرفر والواجهة بتاعتك. دورك:
1. **واجهات برمجية سريعة (FastAPI Endpoints)**:
   - إنشاء نقاط نهاية (REST APIs) لكل الخدمات (رفع الملفات، توليد الأسئلة، تقييم الطالب، الشات).
2. **واجهة استخدام تفاعلية مبهرة (Interactive UI)**:
   - عارض PDF تفاعلي يظلل الصناديق المحيطة بالنص المسترجع (PDF Bounding Box Highlighter).
   - مشغل فيديو وصوت يقفز مباشرة للثانية المحددة التي ورد فيها الشرح.
   - لوحة تتبع معرفية تبين للطالب المفاهيم المتقنة والمفاهيم التي تحتاج مراجعة (BKT Mastery Dashboard).
3. **محرك الاختبارات المعيارية الآلي (Evaluation Harness)**:
   - تشغيل بنشمارك الـ 300 سؤال ومقارنة الأداء التجريبي (ROUGE, Faithfulness, WER).
   - قياس سرعة الاستجابة (P50/P95 Latency) واستهلاك الرموز وتكلفة الـ API عبر `OpenTelemetry`.

## 📂 خريطة المجلد ومسؤولية كل ملف:

```
5_ui_and_eval_harness/
├── api_routes/
│   ├── ingestion_router.py     # نقاط نهاية رفع ومعالجة المستندات والتسجيلات
│   ├── rag_router.py           # نقاط نهاية الشات التفاعلي والتلخيص الهيكلي
│   └── pedagogy_router.py      # نقاط نهاية بنوك الأسئلة وتحديثات الـ BKT وخطط المراجعة
├── streamlit_app/
│   ├── app.py                  # تطبيق Streamlit المتكامل لعرض المشروع أمام لجنة المناقشة
│   ├── pdf_viewer_component.py # مكوّن تظليل فقرات الـ PDF بإحداثيات الـ Bounding Box
│   └── audio_sync_player.py    # مكوّن مزامنة مشغل الصوت مع النصوص المفرغة
├── benchmark_runner/
│   ├── eval_harness.py         # محرك تشغيل الاختبارات وحساب مقاييس ROUGE و Faithfulness
│   └── telemetry_tracker.py    # تسجيل استهلاك الرموز وزمن الاستجابة عبر OpenTelemetry
└── server.py                   # السيرفر الرئيسي المجمع لـ FastAPI
```
