# 🧠 Service 2: Hierarchical Memory & Pedagogical Knowledge Graph (PKG)

مرحباً بك يا مهندس الذاكرة والمعرفة! 👋  
أنت العقل التخزيني للمنظومة؛ بدونك النظام هينسى ويفقد السياق الدلالي!

## 🎯 دورك في المشروع باختصار (Mission):
المحاضرات الجامعية طويلة ومليانة تفاصيل، مينفعش نقطعها تقطيع عشوائي ولا نخزنها في ليست عادية. دورك:
1. **التقطيع الهرمي ذي الـ 3 مستويات (3-Tier Hierarchical Chunking)**:
   - **Level-0 (Micro-chunks)**: مقاطع صغيرة (~200 رمز) للبحث المباشر عن الحقائق.
   - **Level-1 (Parent Sections)**: مقاطع سياقية (~1000 رمز) عشان لما نلاقي معلومة نرجع بالفقرة كاملة للـ LLM.
   - **Level-2 (RAPTOR Summaries)**: ملخصات هرمية للمحاضرة كلها عشان نجاوب على الأسئلة الشاملة بدون ما نتوه في التفاصيل.
2. **التضمين الدلالي (BGE-M3 Embeddings)**:
   - تحويل المقاطع لمتجهات بأبعاد 1024/384 تدعم العربي والإنجليزي، وتدعم البحث الكثيف (Dense) واللفظي المتناثر (BM25).
3. **قاعدة بيانات Qdrant المتجهة**:
   - تخزين المتجهات وعمل بحث هجين (Hybrid Search with Reciprocal Rank Fusion - RRF).
4. **بناء شجرة المعرفة (Pedagogical Knowledge Graph - PKG)**:
   - استخراج المفاهيم الأساسية، والربط بينها بعلاقات اعتمادية: "عشان تفهم المفهوم B لازم تكون فاهم المفهوم A الأول" (`PREREQUISITE_OF`).

## 📂 خريطة المجلد ومسؤولية كل ملف:

```
2_memory_and_pkg/
├── embeddings/
│   ├── bge_m3_embedder.py      # توليد المتجهات الكثيفة والمتناثرة لنموذج BGE-M3
│   └── raptor_clusterer.py     # تجميع المقاطع المتشابهة وتوليد ملخصات المستوى الثاني
├── vector_stores/
│   ├── qdrant_manager.py       # إدارة مجموعات Qdrant وتطبيق فلاتر المحاضرات والبحث الهجين
│   └── payload_schema.py       # هيكل البيانات الإضافية المخزنة مع كل متجه (Metadata)
├── knowledge_graph/
│   ├── concept_extractor.py    # استخراج المفاهيم العلمية من المحاضرة
│   └── prerequisite_miner.py   # كشف علاقات المتطلبات السابقة وبناء حواف شجرة الـ PKG
└── memory_service.py           # المنسق العام لاستقبال المستند وفهرسته وبناء الرسم المعرفي
```

## 🔄 ترتيبك في الفريق (مين هيديك ومين هتسلم له):
* **📥 مين بيديك داتا؟**  
  مهندس الـ Ingestion (**Service 1**) بيسلمك كائن `UnifiedDocumentAST`.
* **📤 مين هتسلمه داتا؟**  
  - مهندس الـ RAG (**Service 3**): بتديه واجهة بحث يسترجع منها المقاطع الأكثر صلة بالسؤال.
  - مهندس الذكاء التعليمي (**Service 4 - Pedagogy**): بتديه شجرة المفاهيم وعلاقاتها عشان يبني عليها الأسئلة.
